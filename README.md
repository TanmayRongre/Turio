# 🌍 Turio — Travel & Tourism Website

A modern, fully responsive travel and tourism website built with **React 19**, **Vite**, and **Tailwind CSS 4**.

## ✨ Features

- 🎬 Full-screen hero video background
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🍔 Mobile hamburger menu with fullscreen overlay
- 🗺️ Interactive destinations carousel with 9 destinations
- 🔄 Sticky navbar on scroll
- ⚡ Lightning-fast with Vite

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | UI Framework |
| Vite | Build Tool |
| Tailwind CSS 4 | Styling |
| React Router DOM | Client-side routing |
| Lucide React | Icons |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/TanmayRongre/Turio.git

# Navigate into the project
cd Turio

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 📦 Build for Production

```bash
npm run build
```
